# Task 1: Modern Frontend Development - Developer Productivity Dashboard

A responsive productivity dashboard built with React.js/Next.js and Tailwind CSS as part of the Innovation Hacks Full Stack Development Internship.

## Features
- Clean responsive dashboard layout with sidebar navigation.
- Dynamic search and status filtering for tasks.
- Component-driven architecture with loading and empty state handling.
- Built with Tailwind CSS for cross-device responsiveness.

## Setup Instructions
1. Clone the repository: `git clone <your-repo-link>`
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open `http://localhost:3000` in your browser.
